Privacy policy

Last updated: October 5, 2026

In short: Maestro is free, open-source software that runs on your own machine. There are no accounts. This website sets no cookies, runs no analytics and loads nothing from third parties, and the Maestro software sends nothing to us.

This website

  • No cookies, no analytics, no trackers. The site does not set cookies, does not use analytics or advertising scripts, and loads no fonts, scripts or images from other servers.
  • No accounts or forms. There is nothing to sign up for and nothing you type on this site is sent anywhere.
  • Server logs. The site's own server prints the method, path and status of each request to its console, without IP addresses or browser details. The site is hosted on Railway, whose infrastructure may keep its own request logs under its own privacy policy.
  • Browser storage. None. The site keeps nothing in your browser's storage.

The Maestro software

Maestro runs on your computer. It has no account system, no telemetry and no server of ours to talk to.

  • API keys that you add are stored only in ~/.maestro/keys.env on your machine (file mode 600). A key is used only to authenticate to its own provider and is never printed, logged or returned by Maestro's local API.
  • Subscription logins (Claude Code, Codex, Gemini CLI) are checked for presence only and used through their official command-line tools. Maestro never reads or forwards their tokens.
  • Prompts go only to the model provider Maestro routes them to, or to a model server you run. Maestro's local request log (~/.maestro/maestro.db) records the model, job, category, timings and token counts, and stores prompt text (the first 120 characters) only if you turn on log_prompts.
  • Optional Jev classifier. Only if you set TYPESAFE_API_KEY, Maestro sends each routed task's text (up to 4,000 characters) and the names and descriptions of your candidate models to TypeSafe to choose a model. Without that key, or with --classifier rules, every routing decision stays on your machine.
  • Network scans of your local subnet happen only when you run maestro-router detect --scan.

Your use of each model provider is governed by that provider's own terms and privacy policy.
