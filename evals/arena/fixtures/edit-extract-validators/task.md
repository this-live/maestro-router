`shop/models.py` is getting too big. Move the validation code (`ValidationError`, the `validate_*` functions and the constants they use) into a new module `shop/validators.py`. `models.py` should import what it needs from there, and keep re-exporting `ValidationError` and the `validate_*` functions because other teams still do `from shop.models import validate_email`. Switch `shop/api.py` and our tests over to importing from `shop.validators`. Pure refactor, no behaviour changes.
